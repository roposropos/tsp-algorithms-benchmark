# Stage 3 - Simulated Annealing

C++ implementation of Simulated Annealing for generated, TSPLIB and ATSP instances.

## Build

```bash
make
```

## Run

```bash
make run-generated
make run-mixed
```

Or directly:

```bash
./build/pea_sa config/sa_generated.txt
```

## Outputs

- `results/sa_results.csv`
- `results/sa_summary.csv`
- `results/sa_generated_results.csv`
- `results/sa_generated_summary.csv`
