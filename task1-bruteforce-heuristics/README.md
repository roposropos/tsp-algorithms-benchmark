# Task 1: brute force and classical heuristics

Python implementation of four approaches to TSP:

- brute-force enumeration;
- random route search (RAND);
- Nearest Neighbour (NN);
- Repetitive Nearest Neighbour (RNN).

The program is controlled by text configuration files and exports CSV results.

```bash
python3 tsp_task1.py config_bruteforce.txt
python3 tsp_task1.py config_heuristics.txt
```
